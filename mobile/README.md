# Network QoS Monitor — Android

Aplicación móvil del TP5. La instalación, compilación y límites están
en el [README principal](../README.md).

- Guía breve: [Word de instalación y uso](../entrega/TP5-Network-QoS-Guia.docx).
- Arquitectura: [decisiones y límites](../docs/arquitectura-y-limites.md).
- Entrega validada: Android en Samsung A55. La carpeta iOS pertenece a
  la plantilla y no representa una implementación iOS validada.
- Para instalar dependencias: `npm.cmd ci` desde esta carpeta.
- El APK Standalone incorpora JavaScript y no requiere Metro.
